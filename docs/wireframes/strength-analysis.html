  1. New Analyse tab. Reads the layup already defined in Design. Nothing here changes the winding program.
  2. Load cases. Saved, named cases. Presets fill the four basic loads: pressure, airframe (bending plus compression), shaft (torque), or custom. Any combination can be entered.
  3. Ply properties. Start from a textbook set, clearly tagged. "Tested values…" opens the editor in frame 4.
  4. Method. Failure criterion, the reserve factor you require, and a knock-down for wound laminates (crossovers, voids).
  5. Part shaded by reserve factor. Weakest region hatched as well as shaded, and labelled, so it does not rely on colour alone. Toggle to stress or plain fibre view.
  6. Along-the-mandrel chart. Matches the existing wall build-up chart. One line per load case, the required level drawn across, lowest point marked. Click a station to open frame 2.
  7. Verdict. One number, a plain pass or fail against the requirement, and where, which ply and how it fails first.
  8. Capacity. The load each basic case could reach before first failure, so you see headroom without entering more cases.
  9. Stiffness. Wall moduli and tube stiffness. Useful on its own for airframes and shafts.
  10. To decide: also show a small "reserve factor" tile in the Design summary, so layup edits show their effect without switching tabs?

  1. Variants. "Snapshot current" freezes the layup you have now; then keep editing in Design and snapshot again. Each variant keeps its own full winding plan.
